# Automated Certificate Generation System

## Overview

An automated certificate generation system built using Google Sheets and Google Apps Script. The project automates certificate creation using information stored in a spreadsheet, reducing manual effort and improving efficiency.

## Technologies Used

* Google Sheets
* Google Apps Script
* Google Drive

## Features

* Uses spreadsheet data to generate certificates.
* Automates repetitive certificate creation tasks.
* Simplifies certificate generation and management.

## How It Works

1. Store recipient information in Google Sheets.
2. Run the Google Apps Script.
3. Generate certificates using the available spreadsheet data.
4. Save the generated certificates to the configured destination.

## Project Files

* `Code.gs` — Google Apps Script code.
* `Certificate.html` — Certificate template, if applicable.

## Setup

1. Create a Google Sheet containing your certificate data.
2. Open Extensions → Apps Script.
3. Add the project files from this repository.
4. Configure the certificate template and destination.
5. Run the script and authorize the required permissions.
